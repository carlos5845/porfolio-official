# Carpeta de Eventos

Coloca aquí las fotografías de tus eventos, conferencias, hackathons o talleres.

Ejemplo:
- `coneisc-2024.jpg`
- `hackathon-puno.jpg`
- `workshop-ml.jpg`

Luego, en `components/sections/EventsSection.tsx`, solo actualiza la propiedad `image`:
```ts
image: "/events/coneisc-2024.jpg"
```
